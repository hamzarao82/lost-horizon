## Checks

| Check | Rule |
|---|---|
| Duration | Inside the band in the table below |
| Clipping / level | Peak below 0.99 and above 0.2; RMS inside the band |
| DC offset | Absolute mean below 0.02 |
| Loop seam | Loops only: |first sample − last sample| below 0.05 |
| Spectral centroid | Magnitude-weighted mean frequency of a 4096-point Hann-windowed FFT, inside the band |

## Seam ease (why the loop seams are exactly 0)

Before the ease, the wrap jumped by one natural sample step, which for noise-based loops was above the
0.05 limit (measured before the change: ambience_trail 0.181, menu_wind 0.130, ambience_jungle 0.087,
rain_loop 0.045, ambience_coast 0.030, boat_engine 0.016). `_seam_ease` in `tools/gen_sfx.gd` eases the last
0.25 s of each loop with a sin² ramp so the final sample equals the first. The length is unchanged. The ramp
moves the tail by at most the original seam difference, so it cannot click.

## Filters

`_lowpass` is one-pole (6 dB/octave). The new rumble and impact sounds use `_lowpass2` (two cascaded
one-poles). Without it, boat_engine measured 1714 Hz, storm_impact 3813 Hz and machinery_hum 2940 Hz,
all outside their intended bands.

## Regenerated bytes

Shortening the loops shifts the shared noise sequence, so later noise sounds (ambience_facility, bird_flush,
metal_creak, menu_thunder, explosion, armor_break, enemy_windup_heavy) have the same design with a new noise
realization. Their names are unchanged.
