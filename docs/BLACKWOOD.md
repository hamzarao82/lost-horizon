# Blackwood (Milestone 7 region)

Status date: 2026-11-06. Legend: **Implemented**, **Partial**, **Verified** (a test or a screenshot that was run), **Not tested**.
Scope of this branch: the Blackwood region content as a self-contained builder, its three missions, its puzzle, encounters, persistence rules and tests. The region framework (`RegionManager`, save v4, transitions) is built by another branch; this region only exposes the contract it needs.

## 2. Region contract (for the framework)
`Blackwood` exposes `region_id = &"blackwood"`, `ambience_name = "blackwood"` (metadata only, no new audio), `entry_points` (`from_dead_coast`, `from_underground`), `exit_points` (`to_dead_coast`, `to_research_complex` with `requires_flag = blackwood_research_complex_access`), `exit_locked(id)`, `capture_state()` / `restore_state(data)` (puzzle dials and gate), `build()`, and `static apply_environment(world_env)` (dark green fog, light enough to read). Exit points are data only: the framework places the `RegionExit` triggers.

## 3. Layout (local frame, the route runs towards -Z for about 270 m)
Jungle Entrance (0, 0) - Overgrown Military Trail - Abandoned Patrol Camp (-30, -100, with a stream crossing) - Research Perimeter (-10, -165, fence line at z -185 with the concealed gate) - Experimental Testing Site (-10, -215, concealed hatch) - Research Facility Entrance (-10, -258). Hidden Communications Station (32, -138) is on an unmarked branch off the trail. Lit amber lanterns mark the main trail only. An observation platform with a ramp at (-46, -68) gives height variation; two watchtowers stand at the perimeter. Solid fences run to the region walls, so the gate is the only way through.

## 4. Missions (existing `QuestManager`, no new quest system)
1. **Into the Blackwood:** enter, follow the trail, search the abandoned patrol gear, survive the ambush (flag `blackwood_ambush_cleared`), find the camp. Optional: read both patrol logs. Reward: credits, two bandages.
2. **Ghost Frequency:** find the station, read the technician's frequency log, restore the station (flag `blackwood_comms_power`), read the encrypted transmissions (flag `blackwood_transmissions_read`), recover the research data, find the Black Site link (flag `blackwood_black_site_link`). Optional: the technician's notes. Reward: credits, armor plate, electronics.
3. **The Experimental Site:** reach the perimeter, open the concealed gate (needs the transmissions), find the testing site, examine both consoles, find the evidence of experimentation, defeat the four defenders (flag `blackwood_site_defenders_cleared`), unlock the way on (flag `blackwood_research_complex_access`). Optional: the concealed hatch, the subject list. Reward: two credit packs, a weapon upgrade kit, the unique Ghost Charm.

Quest XP is raised by registering 260 / 320 / 420 in the progression config at runtime (first_signal pays 400; the default for unlisted quests is 200).

## 5. Puzzle: Ghost Frequency
Three dials (0-9) and a lever. The technician's log gives the channel (4-1-7). A wrong transmission resets the dials only. The answer is always readable in the log, so no saved state can soft-lock it. Different rule from Outpost 17 (match a number, not an order).

## 6. Encounters
| Encounter | Trigger | Content | Notes |
|---|---|---|---|
| Trail patrol | entering the jungle | 2 soldiers walking the trail | existing `PatrolGroup`; shares the global cap of 4 active patrollers with Outpost 17 |
| Ambush | `blackwood_ambush_zone` | 2 soldiers + 1 elite hunter from the flanks | warning caption and signal at once, enemies appear 1.5 s later, start hostile |
| Perimeter guards | entering the perimeter | 2 elite hunters + 1 soldier | start idle, notice the player |
| Site defenders | entering the testing site | 1 heavy, 1 elite hunter, 2 soldiers | clearing sets `blackwood_site_defenders_cleared` |

Awareness: encounter enemies set `coordinate_alarm`, so when one notices the player, allies within 10 m (one hop, one scan of the enemy group) join the chase. The flag is off by default; existing enemies and tests behave as before. The trail patrol is spawned by `PatrolGroup` and does **not** use it.
Persistence: a cleared encounter sets `blackwood_<id>_cleared` and never returns; an unfinished one restarts when the player re-enters.

## 7. Persistence
All ids are flags of the form `blackwood_<id>` or `doc_<id>_found`, because `WorldState` keeps only `a-z`, `0-9` and `_` up to 48 characters when saving and drops anything else (a dotted id like `blackwood.<id>` would silently vanish on the first save). Crates use `SupplyCrate`'s own `<id>_taken` flag. Rewards come from the quest rewards, paid once by `QuestManager`, and Progression's rewarded-quest list stops repeat XP.

## 9. Not verified or not done
- **Visual quality:** four screenshots were looked at. The region is readable and distinct from Outpost 17 (dark green, dense palms, lit trail), but it is built from the existing low-poly kit: palms and bushes are scaled kit meshes, the background behind the trees is a flat dark teal, and buildings are boxes. The mast cables read as black lines. It does not look like the reference images.
- **Not played by a human:** ambush fairness and feel, perimeter and defender difficulty, whether the unmarked branch is findable, trail readability in motion.
- **Audio:** only metadata (`ambience_name`) and a `bird_flush` sound request that has no audio file, so the ambush warning is a caption and a signal today.
- **Hatch:** it can be found and examined; the underground it leads to does not exist (`from_underground` entry point is defined for the framework).
- **Quest registration:** the quests are registered into `QuestManager.quests` at build time because `QuestManager.QUEST_PATHS` is not edited here. Loading a save that already has a Blackwood quest active, before the region is built, would find no quest data. The framework should call `BlackwoodQuests.register(QuestManager, Progression)` at startup, or the three paths should be appended to `QUEST_PATHS`.
- **Performance:** frame rate was not measured; Android and web untested. The vegetation scale and view range are parameters (`density`, `view_range`) for lower quality levels, not wired to the settings.
- **New enemy types:** none; the existing soldier, elite hunter and heavy are reused.
