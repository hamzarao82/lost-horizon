# Asset ledger

Every shipped asset must be listed here with its source and licence.

## Audio
All audio is procedurally generated by [tools/gen_sfx.gd](../tools/gen_sfx.gd) from noise and sine/saw oscillators.
No external recordings, packs, samples or AI-generated audio are used, so there is no third-party licence or attribution.

Regenerate: `Godot_v4.7.2-stable_win64_console.exe --headless --path . -s tools/gen_sfx.gd`

| File | Use | Length | Format |
|---|---|---|---|
| swing_light.wav, swing_heavy.wav | player attack swings | 0.18 / 0.32 s | 22050 Hz mono 16-bit |
| hit_light.wav, hit_heavy.wav | player hit lands | 0.16 / 0.30 s | same |
| hurt.wav | player damaged | 0.28 s | same |
| dodge.wav | player dodge / enemy sidestep | 0.26 s | same |
| pickup.wav, equip.wav | item collected / gear upgraded | 0.29 / 0.45 s | same |
| heal.wav | medkit used | 0.50 s | same |
| enemy_swing_windup.wav | enemy attack telegraph | 0.35 s | same |
| enemy_death.wav | enemy defeated | 0.55 s | same |
| wave_start.wav | new wave fanfare | 0.92 s | same |

Total: about 740 KB.

## Code and visuals
Placeholder capsules and boxes built in Godot; no imported art. `icon.svg` is hand-written.

## Imported 3D props (Milestone 5 visual pass)
Source: Poly Haven (https://polyhaven.com), licence CC0 1.0 (public domain, commercial use allowed, no attribution required; credited here anyway). Downloaded as 1k glTF through the public API (`https://api.polyhaven.com/files/<id>`), textures downscaled to 256 px and re-exported as one GLB each with `tools/blender/import_polyhaven.py` (origin moved to the base centre, JPEG textures at quality 85).

Quaternius and Kenney packs were checked: their downloads are behind Patreon/JavaScript pages that could not be fetched unattended, so no palms or foliage were imported. Palms, bushes and rocks remain the procedural Blender kit pieces from Milestone 2 (`palm_a`, `palm_b`, `bush`, `rocks_*`), now scattered with `scripts/world/vegetation_scatter.gd`.
