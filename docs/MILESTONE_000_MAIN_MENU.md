# Milestone 0: Main Menu Overhaul

Status date: 2026-11-14. This document records the brief, an audit of what the menu is today against each step of it, and an honest acceptance table. **Most of the visual and audio work was built earlier as part of the Opening Experience (`OPENING_EXPERIENCE.md`); two requested items are not built: the real player model in the menu scene, and the brief-style combat imagery.** Legend: **Implemented**, **Partial**, **Not built**, **Verified** (a test or screenshot was run), **Not tested**.

## 1. The brief (summary)
Upgrade the main menu into a cinematic presentation: dark ocean, distant island, storm clouds, lightning, subtle motion, a protagonist side-profile composition using the real player model, occasional brief combat imagery if feasible. Title "LOST HORIZON / BLACK SITE". Options New Game, Continue, Settings, Credits, Quit, all existing behaviour preserved. Ocean ambience, wind, distant thunder, selection sounds. Must work at 800x360, 1280x720 and 1600x720; stay compatible with the GL Compatibility renderer, Windows and single-thread web; no expensive shaders or particles. Out of scope: the speedboat cinematic, the beach sequence, any mention of Outpost 17, any story or quest change.

## 5. Known limits and open questions
- **Menu size, 800x360:** the project uses stretch mode `canvas_items` with aspect `expand` on a 1280x720 base. The main page needs about 674 of 720 virtual pixels, which scales to about 337 px tall at 800x360, so it should fit but small. **This size is not in `ui_layout_check` (which covers 1280x720, 1600x720 and a tall 1280x2844 phone shape) and has not been looked at.** The 1600x720 case is tested.
- The page is nearly full at 1280x720; adding a sixth button would need the layout reworked.
- Selection feedback is click only; there is no hover or focus sound.
- Nobody has listened to the generated wind, waves and thunder, and the mix levels (-16 dB wind, -11 dB waves) are unjudged.
- The title is text on a procedural background; there is no logo artwork.

## 6. What finishing this milestone would take
1. Add 800x360 to the menu layout check and take screenshots at all three sizes.
2. Build a `SubViewport` with its own world, load the real player scene, pose the idle clip in side profile, and light it with the lightning flash. Check the cost on web and on integrated graphics first.
3. Optionally cut a short combat loop from existing attack clips if step 2 is affordable.
4. Measure the menu: frame time, draw calls, memory, on desktop and in a web build, and add the numbers to `PERFORMANCE_BUDGET.md`.
5. Add a hover sound only after listening to `ui_click`.
6. Run the web build once and confirm the loading progress bar still advances.

Steps 2 to 4 are the real work. Steps 1, 5 and 6 are small.
